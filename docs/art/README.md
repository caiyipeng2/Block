# 特殊图案获选基准

`approved-inset-symbols.png` 是用户在 2026-10-16 最终确认实装的原生成预览，原样复制，不是 Godot 实机截图。

- 尺寸：1322×1190。
- SHA256：`a11dfdcb776d8f34fc55c8d56bcbd200efa1ab53388751323f178b4a4eeebea3`。
- **仅右列「立体提亮预览」为最终实现基准**；左列为上一轮嵌合对照。
- 采用：方正暖黄褐斜面底托、同形浅槽、窄槽壁/接触暗缝、红六角星与黄五角星的凸面折线、金橙五边形宽亮前面和下右暗斜面。
- 不采用：更早被拒绝的大圆角糖果/亮面塑料风、单纯贴片或粗黑描边。

`0.8.2` 最初使用现场三角面近似复现；用户于 2026-10-19 反馈实际图案碎裂、模糊且锯齿重。该实现没有使用批准原图纹理，薄槽边和密集小切面直接采样是主要差异来源。

`0.8.3` 保留现有暖黄褐底托，图案改为 [透明 SVG 图集](../../assets/ui/targets/README.md) 的宽切面、线性渐变和抗锯齿轮廓。图集独立于这张批准记录手工重绘，不声称逐像素提取；只取右列的视觉方向，不带入对照文字或蓝色背景。两行共用同一符号定义，仅方块内版有槽口；HUD/开局/飞行/结果使用独立形态。无损导入、生成 mipmaps，CanvasTexture 固定资源级过滤，已有蓝钻兼容。

本目录是批准记录，`.gdignore` 阻止 Godot 将其作为运行资源导入，现有导出规则 `docs/*` 也排除本目录。图形实装与原图相似度、24/30px 小格辨识度仍需用户在 Godot 验收；批准预览不等同用户已验收源码。
