# Block 三种模式说明

更新：2026-10-15；源码版本：`0.5.0`。本文件记录当前代码目标与用户验收口径，不能作为运行验收通过的结论。`0.3.0` 全关分数目标、`0.4.0` 的 2→12 个单类标记与首组清完全部目标的方案，均已被下文覆盖；`0.4.1` 的地图比例、植物美术和首两关教学推进继续保留。

## 模式与共同规则

| 模式 | 开局 | 结束与记录 |
|---|---|---|
| 自由 | 原有 8×8 空棋盘 | 无积分上限；无合法落点时结束；沿用旧版最高分 |
| 经典 | 每局按种子随机预置约 16–24 格，保留空格、不生成满行/列 | 无积分上限；无合法落点时结束；独立最高分 |
| 闯关 | 固定关卡种子、布局与首轮托盘；第 3 关起在初始占用格中设置特殊标记 | 完成本关目标即通关；第 1、2 关采用教学推进托盘，第 3 关起无合法落点时失败；保存逐关进度与关卡最佳分 |

三种模式共同保留每轮三块、普通方块每块 3–5 格、不旋转、任意放置顺序、行列同时清除、交叉格只清一次、不下落。仅第 1、2 关必要时允许 1–2 格救援块，使用范围见下文，全局形状池与形状校验不放宽。合法放置每格 ×10，清除另行加分，多线倍率只作用于清除分；非法释放不加分。预置方块不产生分数、清除统计或连击，不执行开场自动消除。没有新增倒计时、付费道具或提前可放性提示。

## 当前闯关目标

默认关数为 `ModeCatalog.MAX_LEVELS = 96`。关数仍是可调整的实现默认值，不将参考图数字视作用户已确认的最终关数。

| 关卡 | 目标类型 | 达成条件 | HUD |
|---|---|---|---|
| 第 1 关 | 分数 | 本关积分达到或超过 368 | 当前分数 → 368 |
| 第 2 关 | 分数 | 本关积分达到或超过 392 | 当前分数 → 392 |
| 第 3–96 关 | 双类收集 | 清完本关红星与金色宝石；总量按非线性阶梯从 8 增至 40 | 两类剩余数量分别显示，积分独立展示 |

目标类型与数量唯一来源为 `ModeCatalog.objective_config()`；选关说明通过 `objective_description()` 读取同一配置。第 3 关起 `target_score` 为 0，表示不使用分数作为通关条件，不能将 0 解释为开场自动通关。`0.3.0` 的全关目标分公式及“末关 3448 分”仅属于历史，不再适用于当前收集关。

收集标记分为 **红星 `red_star`** 与 **金色宝石 `gold_gem`**，都位于初始真实占用格上，以香槟色底托、深色粗轮廓和曲面高光区分底部方块。同款图标用于棋盘、HUD、飞行反馈和开局目标面板，满线统一颜色不能抹掉图案。

只有所在格随完整行或完整列被真正清除时才收集；预览、无效释放和放在标记附近都不计数。交叉格只收集一次；清红星只减少红星剩余数，清宝石只减少宝石剩余数，**两类剩余都为 0 才通关**，不能用一种目标抵扣另一种。

当前默认目标总量按下表分段，具体两类数量由同一关卡配置给出；金色宝石的配置比例随进度约从 25% 增至 50%，整数数量以 `objective_config()` 的实际结果为准：

| 关卡 | 目标总量 |
|---|---:|
| 3 | 8 |
| 4 | 10 |
| 5 | 12 |
| 6–8 | 14 |
| 9–11 | 16 |
| 12–17 | 18 |
| 18–23 | 22 |
| 24–35 | 24 |
| 36–47 | 28 |
| 48–71 | 32 |
| 72–95 | 36 |
| 96 | 40 |

收集关仍正常累计放置分、清除分和关卡最佳分；分数与目标计数分开展示。即使积分很高，只要还有目标标记未清除，就不会通关。合法放置和非法释放的计分规则均保持原样。

目标达成判断优先于失败和补充下一组三块。达成后停止继续落子和补块，保存进度，反馈结束后显示通关面板。失败不解锁下一关；最后一关没有越界的下一关按钮。

## 收集关开局目标面板

进入第 3 关及以后的收集关时，先展示蓝色横带“收集目标”面板：两种目标图标与数量、当前关卡和来自实际目标配置的难度标签，再通过“开始挑战”进入棋盘操作。标签描述本关参数，不展示无数据支持的玩家通过率。

点击按钮或按 **Enter/Space/Esc** 均用于确认开始。面板关闭前，棋盘拖放、常规游戏快捷键和背景控件焦点均被隔离；不能用 Tab 切到底层菜单或在面板后落子。此时按 Esc 的含义是确认开始，不是同时暂停或离开关卡。

窗口缩放保持目标面板及待确认状态；短窗口中内容使用受限高度的原生滚动区，确认按钮可滚动访问，焦点移动时自动揭示。重开本关、重试和进入下一收集关都会重新展示。前两关继续使用分数目标和原教学推进。确认目标不加分、不扣目标，减少动画仅影响表现，不绕过确认步骤。

## 第 1、2 关的持续推进

首两关承担引导和吸引玩家继续游玩的作用。目标保留为 368、392 分，不再以容易堵死的开局或托盘制造教学门槛；持续进行合法落子可以推进到通关，停留不操作不会自动完成目标。

- 生成托盘时，先按当前棋盘优先挑选利于清线的普通 3–5 格方块，并逐步构造能把整组全部放完的证书；不是只验证第一块能放下。
- 每次合法落子并结算行列清除后，重新检查剩余组的完整可放路径。仍有完整路径则保留原组；没有完整路径时，尽可能保留仍可用的组合，只替换为同样剩余数量的可解方块。已落棋盘不撤回、不挪动，动画结束后托盘须与新组一致。
- 构造认证路线的每一步，先在该步模拟棋盘上寻找普通 3–5 格合法点；普通形状全无合法点时才考虑 2 格，2 格也无合法点才用 1 格。因此一组托盘可以预先包含后续步骤必要的救援块，并不要求显示小块时当前真实棋盘上已经没有任何普通落点。该能力只在闯关模式的分数目标第 1、2 关内生效，不加入公共形状池，也不放宽其他模式的形状校验。
- 救援不赠送分数、不自动清除、不降低目标。只有玩家真正合法放置才按真实格数计分，清除仍额外结算；无效释放仍不加分。

默认 8×8、每格放置 10 分的配置下，行列清除结算后始终留下空格，必要的一格救援保留下一次合法落子的机会；每次合法落子至少得 10 分。因此从 0 分开始持续合法操作，第 1、2 关分别不超过 37、40 次合法落子可达到目标，实际通常因多格放置和清除更快。此结论依赖默认计分及上述局部救援规则，不能套用于自定义的 0 分配置、第 3 关起或其他模式。

第 3 关起的收集目标、自由模式、经典模式不使用该救援或逐步修复，继续保留玩家选择导致失败的规则；不因此承诺玩家任意落子都能通过收集关。

## 藤蔓地图与界面

地图采用从底部向上攀升的单条 S 形路线，每 12 关设旅程平台，96 关共 8 段。`0.4.1` 将关卡格的可见边长缩至 32–42px，命中区域保留至少 44px，纵向节点间距约 76px；不要将点击区域等同于可见方块大小。已通关为青色，选中为金色，锁定为藏蓝。

植物采用饱和明亮绿色的多层主藤、卷须和叶片，不再以大面积灰暗植物衬托锁关。未解锁只改变关卡格与可操作性，不降低整条藤蔓和叶片的亮度；叶片与节点连接路线，保持向上攀升的方向感。

选中关卡上方有独立金色菱锥，包含上下浮动、轻微摆动、光晕与阴影，不接收鼠标输入。选择已通关关卡时标记随选择移动，不改变解锁进度。隐藏选关页或开启减少动画时停止动态；减少动画下保留静态标记。

新玩家只解锁第 1 关，过上一关才解锁下一关。每次进入选关页自动选择最新解锁关卡，旧关可以重玩。初次进入直接定位；新增解锁后返回时镜头短距离向上移动，避免跨越整张长地图；滚轮、滚动条拖动等手动操作立即取消自动滚动。揭示位置保留标记上方空间，窗口变化只重排布局，不重复播放登场滚动。

游戏目标 HUD 将当前进度与目标区连成一体，数字按实际宽度和字体基线居中，包含首关的 `0`；收集关单独展示红星、宝石的剩余数量，积分独立显示。通关、暂停和失败弹窗采用约 0.18 秒淡入与 0.96→1 缩放，减少动画下即时显示；遮罩和输入锁仍隔离棋盘。

## 开局认证与难度边界

固定种子为 `272912 + 关卡编号 × 104729`，同一版本与配置下可复现初始布局、配色、托盘和目标标记。重试同一关恢复相同布局与全部目标；不会沿用失败局中的收集进度。

前两关保持利于清线的分数开局、教学托盘与局部救援。第 3 关起构造底向上的逐行清除工作区，目标行数随难度由 3 增至 8，认证路线从 1 组扩展到 3 组托盘。全部目标事先放在初始真实占用格中；重放多轮落子、清线后须能收集完整目标，后续不会凭空补出新目标。旧版“三个独立垂直带、首组三块覆盖全部目标”的结构不再约束本版。

关卡保存认证路线对应的计划组与棋盘状态。只有当前占用和剩余目标与相应证书状态匹配时，才供应下一计划组，不能只凭轮次强塞预设托盘。玩家偏离认证路线后，按正常可解生成器提供托盘；这保证新组仍存在完整合法放置方案，**不保证误放之后原目标仍可达**，也不对第 3 关起启用首两关的小块救援。

请求密度随关卡调整，实际占用以目标工作区、形状配置与认证结果为准；**不要求每关占用严格递增，也不声称末关必为 43 格**。默认 8×8 下目标总量按上表 8→40 阶梯增长。修改棋盘尺寸、目标表或形状池后须重新认证多轮路线，不能套用默认配置结论。

第 3 关起后续轮继续使用原可解生成器与少解筛选：候选采样从 1 增至 12，计数上限从 8 降至 2，计数节点预算为 2000；采用的托盘仍需完整可放路径。只有 `exact=true` 且 `count=1` 才能称为确认唯一。达到计数上限或节点预算截断都不能证明唯一；本版保证默认初始收集目标有认证路线，**不保证每关唯一解，也不保证玩家任意落子后都能完成收集目标**。实际难度与响应时间仍待游玩调校。

## 反馈与减少动画

红星和宝石按本身类型飞向对应的目标计数区；收集关的 `+分` 只在棋盘附近短暂飘起，不飞向收集计数，避免误解为减少目标数量。其他模式保留加分向分数区域飞行。两类图案在棋盘和反馈层保持一致、可识别，行列交点只产生一次收集。

减少动画开启时不播放粒子、收集飞行和画面震动，地图标记静止、自动定位和弹窗即时完成；规则结算仍正常发生。视觉棋盘轻震不是 Windows 鼠标或手柄硬件震动。最后提供的 WebP 为 **288×640 单帧图**，无法据此核对参考视频中的连续动作与节奏。

## 保存与兼容

存档仍为 `user://savegame.json`、格式版本 `1`，保留 `high_score`、`classic_high_score`、`adventure_highest_completed`、`adventure_best_scores` 与设置。旧档已通关的记录不清空、不降级；重新游玩第 3 关及后续关卡时使用当前收集目标，历史通关记录不表示已重新验证新目标。

新玩家最高通关为 0；缺少可选字段时使用默认值。成功通过当前已解锁关卡推进连续进度；重玩旧关不回退，只提高最佳分；不能越级解锁。最新默认选择为 `min(总关数, 最高通关 + 1)`。保存失败时选关页与结算面板显示“仅本次运行有效”，后续保存成功再写入完整内存记录。

本版不保存进行中的棋盘、托盘、未完成积分或收集数。暂停和设置返回保留当前运行中的棋局；重试或关闭后重新进入，则从本关固定开局与 0 目标进度开始。

停止旧游戏后按 **F5**，本轮优先核对：
