# 自由、经典与闯关模式

用户新增三种模式：现有空棋盘无尽玩法固定命名为自由模式；经典模式随机生成含预置方块与空格的开局，分数不设上限；闯关模式按编号选关、逐关解锁并保存通过记录。用户已确认通关条件为达到目标分数。

## 规则与内容

- 所有模式共享当前形状池、不旋转、计分、行列清除、任意顺序可解三块生成与无合法落点失败规则。
- 预置格不计分。自由模式空棋盘，经典模式每次新局生成不同的有效预置布局；闯关的关卡种子固定，重试相同关卡保留相同开局与初始三块。
- 闯关目标随关卡提升，达到分数后先判胜，不再补充无用的新组三块；已提交的落子反馈播放结束后显示通关面板。
- 初始格数随关卡提高，布局含不同空洞；生成候选保留完整可放路径。后期对合法候选进行有限样本的解数量与落点分支分析，优先少解；搜索未穷尽不能宣称唯一或把有解判成无解。

## 进度

新玩家只有第一关可进入；通过第 N 关才解锁 N+1。已通过关卡可重玩，记录最高分，但不能跳级解锁。进入选关页默认选中最新解锁关卡，最后一关通过后选中最后一关并显示全通关状态。存档继续 version 1，旧最高分归自由模式，经典最高分、连续通关进度和逐关最高分新增可选字段，历史设置保留。

## 画面与操作

主菜单提供三个明确入口。选关页参考蓝色方块地图，已通关青色、最新解锁金色、未解锁深蓝，支持滚动与键盘焦点，底部按钮开始选中关卡。游戏 HUD 显示模式及闯关目标分数；暂停、设置、重开保留当前模式，闯关退出回选关，通关可直接下一关或返回选关。

源码版本升至 0.3.0，本轮只做必要编译与静态复核，不执行游戏/GUI或测试套件。用户验收进度保存、模式切换、难度和实际布局后再打包。
