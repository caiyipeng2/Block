# 闯关数量与难度配表

用户要求先提供配置表，再通过读表生成特殊方块消除目标，并说明如何配置。本轮以可由Excel/WPS编辑的UTF-8逗号CSV为唯一关卡参数来源，初始96行保留现有数值，不依赖关号推算数量或供块难度。

表路径 `config/adventure_levels.csv`。每关一行，字段为关号、目标类型、分数目标、四类收集数、0–100供块难度、初始图案ID、镜像开关、教学关初始占格数、收集关初始特殊块数、随机种子、难度文案和备注。四类数量独立填写，0表示不收集；支持1–4类非零目标，不要求相邻关卡递增。前两关仍为分数教学及救援，第三关起仍为收集。目标配额与初始物理特殊块数量分别控制，后续托盘继续提供未完成类别。

读取层进行整表严格校验：连续1–96行、无重号漏号、合法数字和模板、教学/收集字段相互一致。数据错误时不可回退公式，主界面弹出文件、行、列和原因，拒绝开始闯关；自由/经典照常可用。重新进入选关或重新开始关卡时重读，新局采用修改后的整表，已进行中的棋局保留其参数快照。游戏状态层显式拒绝无效setup，避免错误配置退化成无目标关。

布局模板以表中ID和镜像读取，初始特殊块按表数量在实际占用格内确定性分配；数量超过模板占格即报错。首盘和后续供块共享表内difficulty/100，不宣称难度值等于唯一解比例。Godot导入设置保留CSV原文，导出预设显式包含该CSV。

交付包含96行可编辑表、字段说明及非线性配置示例；已有目录用例维护为读表同源和非法表边界，不执行用例或GUI，仅相关脚本语法检查、CSV数据一致性和静态审查。版本0.6.7，提交并推送origin/main，实机玩法和难度由用户验收。
