# 三模式消除放置预览

用户要求所有模式在拖动至可消除位置时变色并显示彩色发光边框，参考 `20261016-165050.mp4`；本轮直接按该已指定效果实施，不修改消除或供块规则。

## 视频观察

视频为 540×1172、30fps、约 24.15 秒。三行预览区间为 [0.200,1.133)、[1.800,3.700)、[4.633,5.067) 秒，统一金黄色，每条预消除行有细亮边和横向彩虹柔光、内部亮分隔及少量白色闪点；不是棋盘全框。1.133、3.700 秒移出后立即恢复原颜色并撤边。15.800–17.200 秒单红行主要为红色柔光与白亮边。释放后切入已有清除反馈；视频多线清除开头另保留约两帧空心光框，本轮不另加延迟，接回原有清除动画。

参考视频按拖动块色变色，本项目保留用户更早确认的多数色/平票先放及交叉整组去重规则，预览、拖动和实际清除仍一致。未从参考推断计分或供块算法。

视频没有列或行列交叉样本，本轮沿相同视觉规则扩展到列与交叉区域，不声称这些扩展来自逐帧证据。合成 MP4 无法反推出原始透明度，柔光和亮线按格子比例近似。

## 实现范围

- 共用 Main 合法拖动预览：复制棋盘模拟后读取 `ClearColorResolver`，仅实际完整行列变色，普通可放位置没有清除光框，非法位置没有清除预览。
- 新增纯表现 `ClearPreview`：单线同主色柔光，多线缓慢变化的彩虹柔光；按预消除格的暴露边和行列分隔绘制细白边，不改变棋盘布局或缩放旧块。
- 持有预览时小幅亮面呼吸和边缘闪点，稳定悬停不重复重建或闪烁。减少动画保留静态边框与变色，关闭漂移/呼吸/闪点。
- 目标图案在变色块上仍最后绘制；目标位置、计数与配额不改。预览不播放得分、赞语、清除或收集声音，不锁输入、不改分数或存档。
- 移出合法点、释放、暂停、失焦、重开、菜单、设置或窗口重排按现有取消拖动路径立即清理。清除阶段继续已有反馈，不叠两套光框。

## 验证边界

维护必要的现有 UI 检查，覆盖三模式、真行/列/交叉预览、不修改棋盘与计分、非法/取消清理。仅执行 Godot `--check-only` 与静态复核，不运行游戏、用例、GUI 或自动操作桌面；最终相似度和手感由用户按 F5 验收。
