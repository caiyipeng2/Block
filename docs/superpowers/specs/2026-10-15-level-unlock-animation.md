# 方格塔新关解锁表现

参考用户 `20261015163920_rec_.mp4`（30fps，8.97秒）：约2.3秒返回地图；2.5–3.4秒暗场和横向蓝色展示带内出现青色立体方块；3.55–4.0秒方块缩小并飞向刚通过的关卡；4.0–4.3秒下一格变金、选中标记出现。只借鉴通关/解锁的视觉顺序，不增加货币或奖励系统。

用户已确认：通关后点击“下一关”，先回选关页播放动画，再由玩家点击开始新关。

实现约2秒的连贯序列：先将刚完成格和新格定位到可见范围，地图轻暗、蓝色展示带与“第 N 关完成”出现；青色方块弹出、短停，然后沿曲线缩入完成格；完成格点亮青色、下一格由深蓝亮为金色并轻弹，金色菱锥跃迁至新格，底部保留开始新关入口。只变视觉状态，不延迟真实进度保存。

Main 仅在首次通关使解锁上限提升时登记待展示事件，选关页激活时消费一次。启动读取旧存档、失败、重玩已通关、完成第96关不生成新关事件。正常下一关经过地图；最后一关和重玩仍可返回地图，保持真实最高解锁选择。连续旧逻辑遗留的多关事件可合并为最新一次，避免长队列。

独立表现层负责暗幕、展示带、飞行方块、落点环和星片；选关页负责实际关卡格变色与标记移动。开始/返回、手动滚动、选择其他关、隐藏、重排、退出和开启减少动画均可结束表现并恢复最终外观；取消后不重播。动效不拦截地图操作，减少动画只做即时最终点亮。游戏棋盘、目标、供块、计分和关卡格尺寸保持当前0.6.5基线。

只执行相关脚本 `--check-only` 和静态复核，不运行GUI或测试用例。版本0.6.6，文档与源码提交并推送origin/main，实机动效由用户F5验收。
