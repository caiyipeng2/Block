# 开屏与模式选择页

用户要求参考菜单截图和 `20261015-194226.mp4` 优化开屏、模式图标和立体选择框。30fps/8.1秒片段的关键顺序为工作室标识、彩色游戏标题和转动方块、标题上移到菜单顶部。当前项目已有三种模式，本轮直接按该方向完善原生Godot界面。

使用蓝紫到清蓝渐变背景、原创彩色凸字BLOCK/青色BLAST与小皇冠。模式从上到下为金色闯关（位置标记）、绿色经典（无限符号）、紫色自由（拼块）；保留设置齿轮、退出和最高分。按钮有深色厚底、投影、高光边、图标徽章和副标题，焦点只描边，真实按压才下沉，避免原先灰置观感。

开屏约2.2秒：FUNBLOCK STUDIO及拼块标识短显；彩色标题弹入、金块短暂旋转；标题上移、三个按钮错峰入场。点击/Enter/Space/Esc可跳过，跳过输入只结束开屏，不穿透启动模式。减少动画直接显示完整菜单。首次进程开屏一次，返回菜单只播短入场；隐藏、resize、退出和焦点丢失结清所有临时状态，不遗留透明或disabled按钮。

MainMenu负责菜单与动画，MenuLogo和MenuModeButton独立矢量绘制。保留MenuControls下StartButton/ClassicButton/AdventureButton/SettingsButton/ExitButton节点名及原有模式路由，菜单绘制/命中不再由Main重复维护。宽屏居中竖列，与窄/竖窗口自适应，所有操作保留鼠标和键盘焦点。加载图案仅是开场装饰，不制造虚假进度或等待资源。

不修改关卡、配表、失败辅助或存档规则。不自动控制桌面或运行GUI/整套测试，仅维护接口断言及必要语法检查和静态复核，用户F5验收。版本0.7.0，提交推送origin/main。
