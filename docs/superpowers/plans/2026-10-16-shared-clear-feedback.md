# 三种模式共用清线反馈实施计划

**Goal:** 让经典、自由与闯关共用完整的 Combo / Perfect / Excellent / Unbelievable 反馈，保持各自玩法规则。

**Architecture:** 复用现有 MoveFeedback 与 ClearPraise。Main 统一构造普通落子反馈，收集模式再追加目标字段；赞语独立于下一次落子快照，分数飘字起点避让赞语。规则层、供块器、配表与计分不修改。

**Tech Stack:** Godot 4.7.2 / GDScript，沿用系统字体与原有程序化动效。

用户本轮已指定沿用既有闯关表现及玩法隔离范围。按项目约定仅维护必要断言并做轻量 `--check-only`，不执行游戏、GUI 或完整自动验收。
