# 落点预览材质与彩虹质感修订

**Goal:** 消除特殊方块与落点投影色差，并把过重彩虹改成克制的珠光反馈。

**Architecture:** Main 合法落点复用手中/托盘的 `_draw_piece_cell()`；普通落点降为淡投影，满线仍沿真实多数主色。按用户追加的金黄块/局部虹彩柔光截图，ClearPreview 细化光晕、色谱和边宽，MoveFeedback 保留既有波与粒子时序，改在原方块材质上叠少量彩光，避免整块彩虹重涂。

**Tech Stack:** Godot 4.7.2，GDScript CanvasItem，不新增贴图或 shader。

- [x] 定位：落点直接 `draw_block(piece_color)`，手中标记格为 `draw_target_tile()`，产生绿色底层与砂金实块的错配；彩虹高饱和宽带与整格换肤过重。
- [x] Main 合法落点复用 `_draw_piece_cell()`，普通投影透明度改为 .32；满线统一主色及非法释放原有反馈保留。
- [x] ClearPreview 软化渐变、缩窄彩带、低强度柔光并减少闪点，保留正确长轴和彩虹辨识度。
- [x] MoveFeedback 以规则主色/原有特殊格绘制规则为底，加适量珠光扫光与碎片；不再整格高饱和彩虹换肤，目标图案最后绘制。
- [x] 轻量 `--check-only` 与独立静态复核；维护现有检查的色差阈值使其符合降低饱和的新方向，不运行用例或 GUI。
- [x] 更新需求、验收与剩余项，提交/推送由可见计划和最终交付记录确认。

本轮只改表现，规则、计分、供块、目标、存档及原动画/输入锁时长保持。用户按 F5 验收投影、材质、光感和实际消除。
