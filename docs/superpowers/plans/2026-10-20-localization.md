# 中英法全界面语言切换

用户已明确要求实现并逐种语言检查。本次只改变显示语言，保留三模式规则和已有记录。

1. 盘点所有界面、运行提示、弹窗、配置错误与已烘焙进图片的模式标题。
2. 使用统一UTF-8 JSON源文本词典，运行时注册Godot Translation；设置提供中文、English、Français，立即切换并存储language。旧存档默认中文。
3. 更新菜单、选关、HUD、目标介绍、暂停、失败、胜利、确认框、连击及进度漂字。动态数值在翻译模板后插入，避免将格式化后的中文作为key。
4. 按实际宽度适配长文本和法语重音，中文模式按钮保留已批准图片，英法标题使用同材质清除区及独立文本。
5. 在隔离存档中检查三语覆盖、参数、状态不变、存储往返与UI排版；截图核对后构建0.9.0(8)，检查真实包内词典及三星切换。
6. 通过验证后保留0.9.0和0.8.9，清理更早包和导出中间产物，提交并推送origin/main。

语义检查与截图检查分别记录；测试构造的胜利/失败状态不代表实际完成关卡。不得修改手机真实进度以解锁测试界面。
