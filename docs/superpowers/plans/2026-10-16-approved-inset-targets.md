# 获选嵌合图案实装

**Goal:** 实装用户确认的最后预览右列：方正暖黄褐底托、同形浅槽、明亮立体切面的红六角星/黄五角星/金橙五边形。

**Architecture:** 继续使用共用 BlockArt 的原生比例几何绘制，统一改造特殊底托和图案。marker 尾部追加默认 false 的 embedded 参数；方块内使用槽口＋嵌件，HUD/介绍/飞行只画同款亮面嵌件。既有蓝钻按同一结构兼容。普通块、布局、规则、供块与计分不改。

**Tech Stack:** Godot 4.7.2，GDScript CanvasItem 程序化多边形。

- [x] 核对获选原图右列与现有绘制链路，不采用此前被拒绝的大圆角糖果风。
- [x] BlockArt：暖 tan 渐变底托、窄同形槽壁/亮唇、嵌件侧壁与中心折面；各层透明度保留。
- [x] Main/MoveFeedback：棋盘、托盘、拖动、落点预览、回弹和消除标记使用 embedded=true；HUD/开局/飞行/胜利保持独立嵌件。
- [x] 将获选原图原样保存至 `docs/art/approved-inset-symbols.png`，仅为批准基准，不作为截图边框或文字贴入游戏。
- [x] 轻量 `--check-only` 检查生产与相关已有检查，静态复核小尺寸/非方形/星形几何正面积与单次绘制，避免之前的 triangulation 报错。
- [x] 更新需求、验收、剩余项与版本，再提交推送；状态由可见计划与最终记录确认。

用户已明确批准此版实装，无需再次设计确认。按项目约定不运行游戏、GUI、用例或完整自动验收；实际 24/30px 显示、预览相似度与动画由用户 F5 验收。不新增镜像实现的测试；维护已有兼容检查并进行几何静态复核。
