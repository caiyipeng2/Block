# 彩虹光边与实际消除修正

**Goal:** 修复竖列预览近似单色，并把多彩渐变延续到实际消除阶段，适用于三模式。

**Architecture:** 沿已确认清除行/列的长轴采样连续彩虹；单线和多线均保留明显彩色边，方块多数主色规则不变。MoveFeedback 复用预览几何与光谱采样，借原有闪光/扫光/散开进度驱动多彩消除，不新增输入等待或收集时序。

**Tech Stack:** Godot 4.7.2，GDScript，CanvasItem 原生分层光效。

## 原因及修正

- 旧 `_edge_color` 只沿全盘 x 变化 .78 hue，而 y 仅 .025；竖列本身几乎不变色，且单线明确走主色分支。改为行沿 x、列沿 y、交叉沿 x+y 连续变色，单线也使用彩虹。
- 旧白色 core 盖在狭窄、低 alpha 彩色带上；加宽高饱和彩色亮带，缩窄并染色 core，不靠放大棋盘或频繁闪白提升可见度。
- 实际消除旧实现只按主色画 flash/white beam，且不延续彩虹轮廓；改用真实去重清除格的彩虹光膜、轮廓和扫光，短时延续至散开淡出，适量彩色碎片。视频连续帧为时序依据，列与交叉按同一表现扩展。
