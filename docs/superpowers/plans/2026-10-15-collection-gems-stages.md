# 收集体验实施计划

1. 核对 ModeCatalog 首组三块认证限制、GameState 目标坐标计数，以及 Main 输入/启动/反馈生命周期；CodeGraph 已同步但不覆盖 GDScript，限定读取相关脚本。
2. ModeCatalog 提供阶段目标、两类数量、难度说明、目标行数和多轮认证计划；GameState 验证全部轮次，仅在占用及剩余目标一致时供应计划组。维护旧数组目标兼容和前两关隔离。
3. BlockArt 统一宝石绘制；MoveFeedback 保留种类与分别飞行终点；HUD 展示两类剩余数及同款宝石。
4. GameplayControls 新增独立目标弹窗 API；Main 在收集局启动展示、键鼠保护、确认恢复、离开清理；保留暂停、设置、缩放和减少动画行为。
5. 轻量编译变更脚本/相关测试，独立静态复核路线、计数、弹窗与反馈；同步当前需求、三模式、剩余项、验收及版本。
6. 按既有授权提交、推送 origin/main，核对远端 SHA 和干净工作区，交用户 F5 验收。
