## 设置、音频与退出逻辑（2026-10-12）

主菜单新增 Godot 原生“设置”和“退出”按钮，原来的“开始游戏”也使用原生 Button；鼠标按下反馈、键盘 Tab 焦点和空格/回车操作由控件处理。设置界面提供音效、音乐、减少动画三个 CheckButton，显示当前状态，切换立即保存。

- 音效：点击、落子、清除、非法放置四种短音效，关闭开关会停止并屏蔽音效。
- 音乐：基础的原创合成循环旋律；关闭开关停止播放，重新开启恢复播放。
- 减少动画：跳过菜单与设置控件 150 ms 的淡入；规则结果不受影响。本次没有增加方块清除/回弹动画。
- 存档：严格校验版本、分数和布尔字段，缺失/损坏/版本不兼容时使用默认设置；先完整写入同目录临时文件，再替换记录。
- 保存失败：保留旧文件，在设置界面提示“当前设置仅在本次运行生效”，不会误显示保存成功。
- 退出：可见按钮结束游戏运行进程，Godot 编辑器仍保留；从设置按 Esc 返回菜单。
