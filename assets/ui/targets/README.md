# 特殊目标图案

`target_symbols.svg` 是透明、无文字的 1024 × 512 SVG 图集，每格 256 × 256。

| 行 / 列 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 0：嵌合版 | 红六角星 + 窄槽 | 黄五角星 + 窄槽 | 橙五边形 + 窄槽 | 蓝菱钻 + 窄槽 |
| 1：独立版 | 红六角星 | 黄五角星 | 橙五边形 | 蓝菱钻 |

- 依据 `docs/art/approved-inset-symbols.png` **右列**的明亮宽切面重绘。蓝菱钻沿用相同左上光照、右下暗部。
- 两行通过 SVG `use` 复用同一组符号，图案中心、位置、比例完全相同；仅第 0 行增加同形窄槽。槽内接触缝与下侧浅色槽唇不包含整块米黄色底托，底托继续由棋盘绘制。
- 图案以约 (128, 125) 为中心，宽约 160、高约 180 源像素；相邻图集格之间保留至少 40 源像素透明区域，防止 mipmap 串色。
- 使用少量完整大切面和线性渐变；没有滤镜、模糊、外链图片或每帧纹理生成。SVG 作为可维护源资源，由 Godot 导入为纹理。
- `target_symbols.tres` 包装为 `CanvasTexture`，明确指定 `texture_filter = 4`（`TEXTURE_FILTER_LINEAR_WITH_MIPMAPS`）、`texture_repeat = 1`（`TEXTURE_REPEAT_DISABLED`），避免继承调用节点的最近邻采样设置。
- SVG 源保持 1024 × 512、逻辑格 256 × 256；导入设置 `svg/scale = 2.0`，实际纹理为 2048 × 1024、每格 512 × 512，保留拖动与放大时的清晰度。运行时根据纹理尺寸除以 (4, 2) 计算区域，不假设导入后的固定像素尺寸。
- SVG 导入使用无损、生成 mipmaps、修复 alpha 边缘；修改源 SVG 后请保留对应导入设置。所有渐变坐标及 stop 偏移使用显式百分比，符号底轮廓显式无描边，减少 SVG 导入器的继承差异。

该资源改变显示质量和切面表现，不改变特殊目标种类、数量或玩法。
